# ⚾ 위기의 구단! 우리 팀의 약점을 보완하라!

타율과 출루율을 직접 계산하고 소수의 크기를 비교하며, 우리 팀에 필요한 타자를 선택하는 Streamlit 수학 학습 게임입니다.

## 실행 방법

1. Install the requirements

   ```
   $ python -m pip install -r requirements.txt
   ```

2. Run the app

   ```
   $ python -m streamlit run streamlit_app.py
   ```

학생은 영입 목표를 먼저 선택한 뒤 선수 기록을 계산하고, 비교 및 최종 영입 보고서 작성을 진행합니다. 보고서 화면에서 인쇄용 HTML을 내려받아 브라우저의 인쇄 기능으로 PDF 저장도 할 수 있습니다.
